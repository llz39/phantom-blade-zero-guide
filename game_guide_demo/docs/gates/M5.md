## 证据

### 1. 建表

```text
tables: ['cost_log', 'feedback', 'guide_doc', 'trackers']
```

### 2. 匿名会话落库

两次提问（同一 `session_id`，模拟刷新后续聊）：

```text
[1] 200 unknown=True 1448ms :: 暂未收录…
[2] 200 unknown=True 6642ms :: 这个问题按「暂未收录」处理…
```

MySQL：

```text
tracker: ('anon:11111111-1111-4111-8111-111111111111', 4037, 2026-11-08 14:00:15)
tracker: ('anon:ae185bc3-7ad5-4a18-9d96-d0db9060f07f', 2780, 2026-11-08 13:57:05)
```

同一 session 两轮对话后 `state` 从 2780 → 4037 字符，说明状态是**累加复用**而不是每轮新建。

### 3. 反馈落库

```text
POST /api/feedback -> 200 {"status": "ok", "saved": true}
feedback rows: (('11111111-1111-4111-8111-111111111111', 1, 'smoke', 2026-11-08 14:00:44),)
```

### 4. Tracker 类型

```text
[INFO] 创建 TrackerStore: type=mysql, url=<set>
```

修复前该行只会打印 `path`（`Agent.load` 丢参数），现在 url 生效。

## 另外修掉的坑

`_save_feedback` 原来只读 `DATABASE_URL`，而项目用的是 `MYSQL_*` 变量 → 反馈静默不落库
（接口返回 200 但 `saved:false`）。现在改为 `DATABASE_URL` 缺失时用 `MYSQL_*` 拼，实测 `saved:true`。
