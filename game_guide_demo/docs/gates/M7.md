## 连接状态提示（本轮新增）

页面打开时会先探活 `/health`，并把结果直接写在输入框上方，避免把“后端没起”误读成“没有网络”：

| 探活结果 | 页面提示 |
|---|---|
| 探活失败 / 静态打开 | 「后端未连接。现在打开的只是页面本身，`/api/chat` 不存在…」 |
| `agent_ready=false` | 「后端已连接，但 Agent 未就绪，检查 QWEN_API_KEY」 |
| `retriever_ready=false` | 「检索器未连接。Milvus 没起来，此时问答只会回答暂未收录」 |
| 全部就绪 | 不显示提示条 |

发送失败时也不再伪装成内容问题：HTTP 501/404 提示“接口不存在”，网络异常提示“请求没有送达后端”，
错误气泡标为「提示」且不带“暂未收录”标签。截图：`docs/screenshots/offline_notice.png`。
