## 交付物

- `game_guide_demo/addons/milvus_retrieval.py`
  - `MilvusRetriever(InformationRetrieval)`：`connect()` + `search()`
  - collection `game_guide_chunks`，dim 1024，HNSW + COSINE，M=16，efConstruction=200，efSearch=64
  - 标量字段：`doc_id / game_id / doc_type / entity_id / title / content / source / source_level / version / chunk_index / updated_at`
  - 强制 `game_id = "phantom_blade_zero"` 过滤；有 `doc_type` / `entity_id` / `version` 槽位时叠加过滤
  - 同步 Milvus 调用走 `asyncio.to_thread`；异常一律返回 `[]` 并记日志
- `scripts/verify_retrieval.py`：离线 8 项自测 + 在线 20 条查询（含 p95 统计）
