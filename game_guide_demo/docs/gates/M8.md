## 安全自查

- 无硬编码密钥（全仓库 grep 为空；真实值只在 `.env`，已被 `.gitignore` 忽略）
- 不建用户表、无登录接口
- 匿名会话 ID 强制 UUID 校验，避免任意字符串写入 `trackers` 主键
- Milvus 过滤表达式做引号转义，避免表达式注入
- 知识库仅存摘要与短引用，不含攻略原文
- README 明确「非官方」，页面零游戏素材
- 无第三方机构标识（类名、文案、命令行示例、包名均已清理为项目自有命名）
