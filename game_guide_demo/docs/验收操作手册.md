## 1. 必须配置的东西（.env）

文件：`game_guide_demo\.env`（由 `.env.example` 复制，**不要提交 Git**）

| 变量 | 取值 / 从哪拿 | 不配会怎样 |
|---|---|---|
| `QWEN_API_KEY` | 阿里云百炼控制台 → API-KEY | 命令生成、回答、embedding 全挂，接口 500 |
| `LLM_MODEL` | `qwen3.8-flash`（低价，按限制文档） | 用默认值也可 |
| `LLM_API_BASE` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 用默认值也可 |
| `EMBEDDING_MODEL` | `text-embedding-v4`（**不要填本地 BGE 路径**） | 建库失败 / 维度不符 |
| `EMBEDDING_DIM` | `1024`，必须与 collection 一致 | 检索报“维度不匹配” |
| `MILVUS_URI` / `ZILLIZ_CLOUD_URI` | Zilliz 集群地址（`https://in03-xxx...zilliz.com.cn`）；本机 Docker 用 `http://127.0.0.1:19530` | 检索器不初始化，所有回答变“暂未收录” |
| `MILVUS_TOKEN` / `ZILLIZ_CLOUD_TOKEN` | Zilliz 的 API Key；本机 Docker 留空 | Zilliz 连不上 |
| `MYSQL_HOST/PORT/USER/PASSWORD/DB` | 本机实测：`127.0.0.1 / 3306 / root / <你的密码> / game_guide` | 会话不落库，首次提问 500 |
| `TRACKER_STORE_TYPE` | `mysql` | 改成 `json` 只适合临时调试 |
| `CORS_ORIGINS` | `http://localhost:8000,http://127.0.0.1:8000` | 前端跨域被拦 |
| `NO_PROXY` | `localhost,127.0.0.1,::1` | 开着 Clash 等代理时，本机接口会被代理劫持 → 404/网络错误 |

> 本机当前 `.env` 已从原 `ecs_demo/.env` 迁移 Key 与 MySQL 口令，并把 `EMBEDDING_MODEL` 从本地 BGE 改成 API 模型。

## 2. 一次性准备

### 2.1 Python 环境

```bash
cd E:\game_customer_service\game_guide_customer_service
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -e .        # 让 uvicorn 能找到 customer_service_system
```

预期：`python -c "import customer_service_system"` 不报错。
> 若报 `setuptools.build_meta` 缺失：`pip install setuptools wheel` 后重试。

### 2.2 MySQL（本机已完成）

```bash
# 建库建表（已执行过一次，可重复执行，幂等）
.venv\Scripts\python.exe -c "..."   # 或用 mysql 客户端：
mysql -uroot -p < game_guide_demo\scripts\init_mysql.sql
```

预期：`game_guide` 库里有 `guide_doc / trackers / feedback / cost_log` 四张表。

### 2.3 Milvus（已配置 Zilliz Cloud，无需 Docker）

当前 `.env` 已指向 Zilliz Cloud 的 Serverless 集群，`python test.py` 可直接验证：

```text
目标      : https://in03-xxxx.serverless.ali-cn-hangzhou.cloud.zilliz.com.cn
云端      : True
token     : 已设置
连接成功，现有 collections: ['game_guide_chunks']
```

**换了新集群 / token 过期时**：改 `.env` 的 `MILVUS_URI` + `MILVUS_TOKEN`
（或只配 `ZILLIZ_CLOUD_URI` + `ZILLIZ_CLOUD_TOKEN`，`env_bootstrap.py` 会自动映射），
然后 `python scripts/ingest.py --rebuild` 重新建库。

**为什么不用本机 Docker**：`docker desktop start` 能起引擎，但拉起 Linux 容器依赖 `wsl.exe`，
被本机安全策略拦截：

```text
PROGRAM BLOCKED BY SECURITY POLICY - wsl.exe
```

本项目固定使用 Zilliz Cloud，不依赖本地 Docker。
若以后想全本地，两条路：放行 WSL 后自行用 Milvus 官方 compose、或换 Linux 机器。

## 3. 每次验收的操作序列

### 步骤 1 · 自检（1 分钟）

```bash
cd game_guide_demo
..\.venv\Scripts\python.exe scripts\preflight.py
```

预期结尾：`阻塞项 0 个`。任何 `[FAIL]` 先修，不要往下走。

### 步骤 2 · 灌库（首次或改过知识库时）

```bash
..\.venv\Scripts\python.exe scripts\ingest.py --dry-run   # 不花钱，看分块
..\.venv\Scripts\python.exe scripts\ingest.py             # 真正写 MySQL + Milvus
```

预期：`完成: 成功 72 / 失败 0`，`ingest_report.json` 里 `dry_run: false`。
重点看 `milvus_rows` 与 `guide_doc` 行数是否对得上。

### 步骤 3 · 起服务

```bash
..\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

预期日志：

```text
[INFO] 创建 TrackerStore: type=mysql, url=<set>
[INFO] 创建检索器: addons.milvus_retrieval.MilvusRetriever
[INFO] Uvicorn running on http://127.0.0.1:8000
```

### 步骤 4 · 打开页面

浏览器访问 **<http://127.0.0.1:8000/>**。

- 必须由 FastAPI 提供；双击 `chat.html` 或用静态服务器打开都会失败（页面上会红条提示“后端未连接”）。
- 页面顶部若出现红色提示条，直接读提示内容，按提示处理。

### 步骤 5 · 三条冒烟

| 问题 | 期望 |
|---|---|
| 白山风雷剑怎么获得 | 有结论 + 2 张来源卡片，卡片可点 |
| 玉璧怎么打 | 说出位置/掉落；机制没收录就写“暂未收录” |
| 黑神话悟空二郎神怎么打 | 拒答，且**不追问“哪款游戏”** |

同时确认：`trackers` 表新增 `anon:<uuid>` 一行；刷新页面后继续提问，仍是同一 `sender_id`。

### 步骤 6 · 120 题评测

```bash
..\.venv\Scripts\python.exe scripts\run_eval.py --retrieval-only   # 只看召回，最便宜
..\.venv\Scripts\python.exe scripts\run_eval.py --full             # 端到端，会花 LLM 钱
```

产出 `eval/eval_report.json`，写回 `docs/gates/M8.md` 的指标表。
答案准确率需人工抽检：脚本已把每题回答导出。

### 步骤 7 · 门禁签收

按 `docs/gates/M3.md … M8.md` 的顺序补签，每份填「证据 / 未通过项 / 是否允许进入下一阶段」。
M3 顺带核对分块：`ingest_report.json` 里最大块应 ≤700。

### 步骤 8 · 记成本

`docs/成本记录.csv` 每天一行：接口、请求数、token、金额。总预算 ≤200 元，到 80% 停。

## 4. 报错对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面点“问剑”提示 **连接失败 / 后端未连接** | 页面不是由 FastAPI 提供（双击 html、IDE 预览、静态服务器），或服务没起 | 用 `http://127.0.0.1:8000/` 访问 |
| 接口返回 **501 / 405**，页面提示“接口不存在” | 静态文件服务器不支持 POST | 同上 |
| 本机接口 **404**，但服务日志没有请求 | 系统代理劫持了 127.0.0.1 | 加 `NO_PROXY`；curl 用 `--noproxy '*'`；httpx 用 `trust_env=False` |
| 所有回答都是“暂未收录” | **Milvus 没连上**（最常见） | 跑 `preflight.py` 看 Milvus 项；页面红条也会提示“检索器未连接” |
| 启动报 `No module named customer_service_system` | 没 `pip install -e .` 或不在项目根运行 | 在仓库根执行 `pip install -e .` |
| 首次提问 **500**，日志 `Access denied` | MySQL 口令错 | 改 `.env` 的 `MYSQL_PASSWORD` |
| 日志 `Unknown database 'game_guide'` | 没建库 | 执行 `scripts/init_mysql.sql` |
| `embedding 维度不匹配` | collection 与 `EMBEDDING_DIM` 不一致 | 换模型必须 `ingest.py --rebuild` |
| `Fail connecting to server on 19530` | Milvus 没起 / URI 错 / 代理 | 见 2.3；确认 `NO_PROXY` |
| 回答里出现“据某攻略站”但没卡片 | `sources` 未透传 | 检查策略 metadata 与 `ActionSendText` |
