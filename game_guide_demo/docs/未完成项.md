## 四、环境限制与说明

### 4.1 Milvus 走 Zilliz Cloud（本机 Docker 不可用，已绕开）

本机 `docker desktop start` 能拉起引擎，但启动 Linux 容器依赖 `wsl.exe`，被安全策略拦截：

```text
PROGRAM BLOCKED BY SECURITY POLICY - wsl.exe
```

**当前方案**：Zilliz Cloud Serverless 免费集群，`.env` 已配置，`test.py` 连通、**81 条向量**入库。
项目只用这一条路径，不再保留本地 Milvus 的编排文件。
详见 `docs/验收操作手册.md` 2.3。

### 4.2 本机代理会劫持 127.0.0.1

系统设置了 HTTP 代理（Clash 一类）。测试本机接口时如果不绕开，会把
`http://127.0.0.1:8000/api/chat` 当成代理请求发出去，FastAPI 收到的是
`POST http%3A//127.0.0.1%3A8000/api/chat` → 404。处理：

- `.env` 里设 `NO_PROXY=localhost,127.0.0.1,::1`
- curl 加 `--noproxy '*'`
- httpx 用 `trust_env=False`

浏览器访问 localhost 一般会自带 bypass，不需要额外设置。
