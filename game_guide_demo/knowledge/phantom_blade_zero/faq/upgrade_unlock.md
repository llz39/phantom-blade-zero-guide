# 什么时候能强化武器？

## 结论

推进「泣溪谷（Weeping Creek Valley）」主线，在前哨营地与女铁匠对话后解锁强化；之后可以在各处的钟进行强化。

## 注意

不同攻略对“前哨营地”的称呼略有差异，若在营地没找到铁匠，先把该区域主线推完。
