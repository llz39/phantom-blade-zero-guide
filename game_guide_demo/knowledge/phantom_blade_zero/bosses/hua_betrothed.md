# 新娘阿花

> 英文名：Hua, Deadly Betrothed

## 位置

「悲泣溪谷」煞气塔区域的可选首领。路线：塔基后方找地面洞口 → 滑下断桥 → 清掉落地区域的敌人 → 上楼梯见阿花。

该区域没有钟，失败后要重走路线。

## 掉落

红妆鬼斩（Scarlet Wraithblade）。

## 机制与阶段

- 石蒜花控场：铺地、减速、引爆。

- 阶段与血量：暂未收录。
